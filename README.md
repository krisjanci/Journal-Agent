# Journal-Agent
A macOS journal app

## Work Flow

- The app opens and has a simple microphone button

- You speak about your day normally, what happened, how you felt and you answer a few rating prompts on the screen.

- The app transcribes it.

- It plugs in your transcribed information to a local AI that parses it and organises it into a SQLite data structure

- It'll keep it file which can be later analysed for trends etc.
